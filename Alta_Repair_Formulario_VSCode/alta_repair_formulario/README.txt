# Alta Repair Valley — Formulário de recrutamento

## Como abrir no VS Code
1. Extraia o ZIP para uma pasta.
2. Abra a pasta `alta_repair_formulario` no VS Code.
3. Abra o arquivo `index.html` no navegador. Se tiver a extensão Live Server, clique com o botão direito em `index.html` e escolha **Open with Live Server**.

## Arquivos
- `index.html`: estrutura e campos do formulário.
- `style.css`: visual, responsividade e animações.
- `script.js`: cálculo automático de idade e confirmação de envio.
- `logo-alta-repair.png`: logo enviada.

## Importante sobre o envio
Esta versão é um protótipo front-end. Ao clicar em **Enviar formulário**, ela valida os campos e mostra uma confirmação, mas não envia nem salva as respostas em um servidor. Para receber candidaturas de pessoas que acessarem o site publicado, conecte o formulário a um backend ou serviço de formulários. Não publique dados pessoais sem configurar armazenamento e acesso de forma segura.
